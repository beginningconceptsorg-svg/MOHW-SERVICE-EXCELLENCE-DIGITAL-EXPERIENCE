# Automatic intelligence
The default chat uses the source-backed engine immediately. Already-downloaded native browser models can interpret unresolved questions. A 22.8 MB quantized MiniLM model plus runtime supports related-source retrieval on CPU. Automatically downloads only on explicitly detected Wi-Fi/Ethernet, not cellular, unknown metering, low memory, slow networks or Data Saver. A single optional Settings button can request it on other connections. The previous large models are not used by the chat. No external chat inference endpoint. Actual mobile inference and relevance remain to be tested. Browser-native model is never automatically downloaded. Exact facts, calculations and privacy boundaries remain primary.
