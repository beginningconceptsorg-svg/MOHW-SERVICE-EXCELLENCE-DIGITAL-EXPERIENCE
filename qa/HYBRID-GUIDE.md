# Hybrid Service Excellence Guide

The standard source-backed guide remains the default. Open Enhanced intelligence and choose Compact or Advanced, then Enable local AI. Compact uses Qwen2.5-0.5B-Instruct q8 WASM (~512 MB model file); Advanced uses Qwen2.5-1.5B-Instruct q4f16 WebGPU (~1.22 GB model file, requires shader-f16). Runtime and weights are downloaded from jsDelivr/Hugging Face, then model inference runs in a dedicated browser worker. No remote inference API, keys or charges. Data/storage/battery costs and device compatibility vary. Browser storage can evict downloaded model files.

The model rewrites unresolved non-sensitive, non-numeric questions, then attempts the existing deterministic engine. If that fails, it may select a source from a local shortlist. The optional plain-language explanation feature generates a separately labelled explanation alongside the original verified information. Numeric validation is limited and does not guarantee semantic accuracy. No model-generated links, exact calculations, current facts or individual health advice are accepted. The existing direct engine remains primary, and failure or cancellation falls back to it. The model never submits complaints or changes records.

Test: node qa/guide-hybrid.mjs. This is a mocked worker and routing suite, not a real browser inference benchmark. Test Compact and Advanced on target mobile and desktop devices before institutional rollout. Model and runtime upstream licenses and institutional IT approval should be reviewed before production. The guide's source report and existing dated institutional knowledge are unchanged.
