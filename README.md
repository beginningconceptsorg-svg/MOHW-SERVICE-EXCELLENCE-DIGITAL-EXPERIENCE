# Service Excellence in Action

An interactive digital-publication experience for the Ministry of Health and Wellness (Jamaica), developed by Beginning Concepts.

**Project status:** prototype, subject to Ministry content, artwork, voice and distribution approvals. Do not treat this repository as an officially published Ministry report.

The supplied full 74-page internal customer satisfaction report is **not** stored in this public repository. The prototype contains carefully attributed summary research data only; it does not expose confidential qualitative participant accounts or provide an unrestricted report download.

Preview development takes place in the `feature/service-excellence-preview` branch. No production deployment is authorised by repository creation alone.
